# SimCity 4

This is a proof of concept. Do not take it too seriously. iOS only. Source code will be available later. Skip if you're in the anti-AI camp.

## Installation

1. Download the latest release and install it onto your device using Sideloadly or AltStore.
2. Connect your device to a Mac and open Finder.
3. Copy the contents of your `SimCity 4 Deluxe Edition` folder (GOG version) into the app's directory.
